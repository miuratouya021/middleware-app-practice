# middleware-app-practice

## 概要

COACHTECH 教材 Tutorial 10-2「ミドルウェア ハンズオン演習」で作成した成果物です。

ミドルウェアを使って、管理者だけが管理者専用ページにアクセスできるアプリを作成しました。
一般ユーザーやログインしていないユーザーがアクセスした場合は403エラーが表示されるようにしています。

## 使用技術

- PHP 8.x
- Laravel 10.x
- カスタムミドルウェア
- Laravel Fortify（認証）
- カスタムミドルウェア
- MySQL

## 学んだこと

- ミドルウェアを使うことで、ぺーいにアクセスする前にユーザーの権限をチェックできることを学びました。

-

## 動作確認

Laravel Sailを起動して、http://localhost にアクセスします。

管理者アカウント（admin@example.com / password）でログインします。

「管理者ページにアクセス」をクリックすると、管理者ページが表示されます。

ログアウトし、一般ユーザー（user@example.com / password）でログインします。

同じ管理者ページにアクセスすると、403エラーが表示されます。
